About Green Growth - GROOT

A smart plant monitoring system built with Flask and Firebase Firestore for optimal plant growth.

Features
  • Plant Monitoring: Real-time temperature, humidity, and light tracking
  • Smart Irrigation: Automated pump control for optimal watering
  • Data Analytics: Historical sensor data and growth insights
  • Mobile Responsive: Monitor your plants from anywhere
  • Smart Alerts: Notifications for optimal growing conditions
Technology Stack
  • Backend: Python Flask
  • Database: Firebase Firestore
  • Sensors: Temperature, Humidity, Light, Pump
  • UI Framework: Bootstrap 5
  • Real-time: Live sensor monitoring
Getting Started
  1. Install Dependencies: pip install -r requirements.txt
  2. Configure Environment: Copy .env.example to .env and update with your Firebase credentials
  3. Run the Application: python run.py
  4. Access the App: Open http://localhost:5000 in your browser
