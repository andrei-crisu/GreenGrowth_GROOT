About Firebase Flask App

A modern web application built with Flask and Firebase Firestore.

Features
  • Firebase Integration: Real-time database with Firestore
  • RESTful API: Complete CRUD operations for products
  • Modern UI: Bootstrap 5 responsive design
  • Environment Configuration: Secure configuration management
  • Error Handling: Comprehensive error management
Technology Stack
  • Backend: Python Flask
  • Database: Firebase Firestore
  • Frontend: HTML5, CSS3, JavaScript
  • UI Framework: Bootstrap 5
  • Authentication: Firebase Admin SDK
Getting Started
  1. Install Dependencies: pip install -r requirements.txt
  2. Configure Environment: Copy .env.example to .env and update with your Firebase credentials
  3. Run the Application: python run.py
  4. Access the App: Open http://localhost:5000 in your browser
